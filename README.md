# FamilyChat - Приложение для видеозвонков

Приложение для видеозвонков на React и Express с поддержкой WebRTC.

## Возможности

- Создание уникальных комнат для видеозвонков
- Подключение по ссылке
- Видео и аудио связь в реальном времени
- Управление камерой и микрофоном
- Темный интерфейс

## Установка

1. Установите зависимости:
```bash
npm run install-all
```

## Запуск

Запустите сервер и клиент одновременно:
```bash
npm run dev
```

Или отдельно:
```bash
# Сервер (порт 5000)
npm run server

# Клиент (порт 3000)
npm run client
```

## Использование

1. Откройте http://localhost:3000
2. Нажмите "Создать комнату"
3. Скопируйте ссылку и отправьте друзьям
4. Подключитесь к комнате по ссылке

## Технологии

- **Frontend**: React, React Router, Socket.io Client
- **Backend**: Express, Socket.io, UUID
- **WebRTC**: Для P2P видеосвязи
